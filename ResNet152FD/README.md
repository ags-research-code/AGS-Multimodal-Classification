# ResNet152FD

The public data contain only 10 format examples. For formal training or evaluation, first set `AGS_DATA_DIR` to the complete local dataset directory; see the repository-root README.

This module corresponds to the ResNet152FD model in the paper. See `METHODS.md` in the repository root for its inputs and architecture.
Each complete experiment uses independent leave-one-reactor-out three-fold evaluation, splitting the other two reactors 80:20 for training and validation.
Defaults are 5 repetitions, 100 epochs per fold, batch size=12, and an initial learning rate of 0.0005.
The random seed is 42 + 100×(repeat−1) + (fold−1). The test reactor is excluded from training, validation, and weight selection.
Run from this module directory:

```powershell
python src/train.py
```

The three models used for paired statistics can run 20 repetitions with separate output directories:

```powershell
python src/train.py --num-repeats 20 --results-dir results_20 --model-dir models/saved_20
```

Weights and results are generated by actual runs and are not distributed with the repository.
